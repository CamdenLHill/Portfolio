# README: Camden Hill's Portfolio Repository

This repository contains the breadth and depth of the work I've completed during my undergraduate and masters program.

## Work Experience
Describes the three internships I've had thus far and some of the relevant work I completed.

Pictures are included from the "images" folder within the repository, and other details are specified in the "_data/work_experience.yml" file, which is displayed using the "_layouts/resume.html" file.

## Education
The details are specified in the "_data/education.yml" file, which is displayed using the "_layouts/resume.html" file.

## Design Projects
Describes the three most important design projects I've worked on, although more can be displayed. The current layout shows the project teams I've worked on with descriptions of the individual projects.

The current layout only allows for one picture from the "images" folder within the repository because of my limited experience with HTML. Therefore, the single images are combinations of two or more individual images made from screenshoting PowerPoint. The details are specified in the "_data/design_projects.yml" file, which is displayed using the "_layouts/resume.html" file.

## Software Projects
This section contains all of the most complex software projects I've worked on thus far. Each project has a short description of what the code does, but clicking on the permalink for each project links to the folder containing all the project's files.

The details are specified in the "_data/software_projects.yml" file, which is displayed using the "_layouts/resume.html" file. Each software project object described in the yml file has a URL and description. The URL can be any URL, but the easiest thing to do is to take the permalink of the project folder within the repository and paste it into the URL section of that specific project's object.

## Skills
This section lets you name a skill, your level in it, and describe it.

The details are specified in the "skills.yml" file, which is displayed using the "_layouts/resume.html" file.

## Other Sections
There are other sections not actively displayed in the current version of the repository. This is because they don't apply to me specifically, so there was no need to include them in the live website. They were excluded by commenting out the sections in the "_config.yml". If certain features need to be added back into the website, they can be uncommented.
